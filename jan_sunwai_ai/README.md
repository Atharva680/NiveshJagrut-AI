# 💡 The Idea

India does not lack citizen voices.

It lacks a **unified understanding of what those voices collectively reveal about development needs.**

A citizen may report:

> *"हमारे गांव में पानी की समस्या बहुत समय से है..."*

Another citizen may report:

> *"रस्त्यावर पाणी साचतंय आणि पावसात खूप त्रास होतो."*

Another may submit a text request.

Another may communicate through a local administrative channel.

Individually, these may appear to be separate requests.

Collectively, they may reveal a much larger regional development pattern.

---

# ⚠️ The Problem

Public development information is often distributed across different:

```text
Citizen Feedback
       │
       ├── Languages
       ├── Channels
       ├── Departments
       ├── Administrative Levels
       ├── Geographic Regions
       └── Data Systems

                +

Public Information
       │
       ├── Demographics
       ├── Infrastructure
       ├── Development Indicators
       ├── Environmental Conditions
       └── Public Investment
```

The challenge is not simply **collecting complaints**.

The deeper challenge is understanding:

> **Where are the greatest unmet development needs, who is affected, what evidence supports that conclusion, and how does it relate to existing development conditions?**

# 📊 Evidence, Not Just Complaints

A critical principle of the project is:

> **Complaint volume ≠ Development Priority**

Understanding development requirements may require contextual information such as:

```text
Citizen Demand
      +

      +
Infrastructure
      +
Vulnerability
      +
Geography
      +
Environmental Conditions
      +
Existing Investment
```

This distinction is central to the project's intelligence model.

# 🚀 Getting Started

### Backend Setup
1. Navigate to `backend/`
2. Install dependencies: `pip install -r requirements.txt`
3. Create a `.env` file based on `.env.example` and add your `GOOGLE_API_KEY`.
4. Run the server: `python app/main.py`

### Frontend Setup
1. Navigate to `frontend/`
2. Install dependencies: `npm install`
3. Run the dev server: `npm run dev`

### Running the Demo
To simulate a real-world flow (Submission $\\rightarrow$ Analysis $\\rightarrow$ Recommendation):
`python test_flow.py`
